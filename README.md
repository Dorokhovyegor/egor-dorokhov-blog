# Egor Dorokhov Blog

Монолитный блог: React/Vite фронт, Go API и Postgres для лайков, просмотров и посещений.

## Частые команды

```bash
npm run post:new -- "Название статьи" --tag карьера
npm run content:check
npm run check
```

Локальный запуск:

```bash
npm run dev:db
npm run dev:server
npm run dev
```

Подробный сценарий публикации лежит в [docs/publishing.md](docs/publishing.md).
